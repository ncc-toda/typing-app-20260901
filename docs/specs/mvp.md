# Reply Rush MVP 正式仕様

旧稿 [`docs/mvp-spec.md`](../mvp-spec.md) と [`docs/ui-ux-direction.md`](../ui-ux-direction.md)、採用プロトタイプ [`prototypes/concept-a-chat.html`](../../prototypes/concept-a-chat.html) を統合した正本。実装と受入判定はこの文書に従う。

## 1. 概要

IT エンジニアのチャット返信を模した Web タイピングゲーム。相手メッセージへの返信をローマ字で打ち、120 秒で獲得したゲーム内年収を競う。

- 世界観: Slack 風の今どき IT 企業。トラブル多め。主人公はカタカナ語が好きで、返信ごとに控えめなボケを 1 つ入れる。
- 対象: タイピング練習をしたい IT エンジニア・学生。
- プレイ時間: **120 秒**。時間切れで終了し、未完了の返信は加算しない。

## 2. 画面

| # | 画面 | 内容 |
|---|------|------|
| 1 | タイトル・難易度選択 | Reply Rush、難易度 3 カード、開始 CTA |
| 2 | プレイ | Slack 風チャット、ローマ字ガイド、残り時間、累計年収 |
| 3 | 結果 | 最終年収とサブ統計、再プレイ・統計への導線 |
| 4 | 分析・履歴 | 苦手キー / 指 / 動き、プレイ履歴 |

UI 詳細は [`docs/ui-ux-direction.md`](../ui-ux-direction.md)（A案）。デスクトップ優先。狭い画面ではサイドバーを折りたたむ。コントラストは WCAG AA 相当。

## 3. 入力と出題

- 表示: 日本語返信文 + ローマ字ガイド（done / current / pending）。
- 判定: 有限状態の純粋関数。`shi/si`、`chi/ti`、`tsu/tu`、`fu/hu`、撥音・促音・拗音などを許容。かな・英数字・業務チャット記号を扱う。
- 送信: 全文正解で自動送信（Enter 不要）。
- ミス: その位置で止まり、正しいキーまで進まない。
- バックスペース: 1 文字戻す。
- 問題: 難易度ごと 10 問、計 30 問。短文 / 中程度 / 長文。自然な IT 業務チャット。返信ごとに控えめなボケ 1 つ。
- 除外: URL 全文、極端に長いコードブロック、特殊記号の連続。

### 難易度

| 難易度 | 係数 | 返信の傾向 |
|--------|------|------------|
| 初級 | 1.0 | 短い、記号少なめ |
| 中級 | 1.5 | やや長め、@メンション、Issue/PR、軽い Markdown |
| 上級 | 2.0 | 長め・複数行、引用・技術用語・記号多め |

## 4. スコア

返信 1 件完了ごとに加算する。

```
獲得額 = 基礎額 × 難易度係数 × 速度補正 × 正確性補正
基礎額 = 返信の文字数 × 100 円
```

速度は **CPM**（1 分あたりの正しく入力したキー数）で統一する。

```
速度補正 = clamp(CPM / 150, 0.5, 1.5)
```

正確性 = 正しい入力 / 総キー入力。補正は次の点を線形補間する。

| 正確性 | 補正 |
|--------|------|
| 80% 以下 | 0.8 |
| 90% | 1.0 |
| 100% | 1.2 |

80% 未満も 0.8 で打ち止め。90% と 100% の間も線形。

結果画面のサブ統計: CPM、正確性、ミス数、最大連続入力数、返信完了数、難易度。

## 5. 分析データ

プレイごとにブラウザで集計し、終了時にだけ保存する。

- キーごと: 入力回数、ミス回数、ミス率
- 指ごと: 物理キー対応（左手小指〜右手小指）
- 2 キー遷移: 例 `s` → `i` のミス率
- 履歴: 日時、難易度、年収

画面では累積の苦手キー TOP 5、苦手な指、苦手な動き TOP 5、履歴一覧を出す。ヒートマップや高度な統計は対象外。

## 6. データと API

- 初回起動で `crypto.randomUUID()` を LocalStorage に保存する。個人情報は持たない。
- キー単位の生ログは保存しない。プレイ中はブラウザ集計、終了時に一括送信。
- 問題とプレイ結果の正は D1。ローカル D1 と本番 D1 は別データベース。

テーブル: `problems`、`play_results`、`play_key_stats`、`play_transition_stats`。migration は Git 管理。

| メソッド | パス | 用途 |
|----------|------|------|
| GET | `/api/problems?difficulty=` | 難易度の問題一覧 |
| POST | `/api/results` | 1 プレイ分の集計結果を保存 |
| GET | `/api/stats?anonymousId=` | 累積統計と履歴 |

入力は検証する。D1 は Binding API のパラメータ化クエリを直接使う。ORM は使わない。

## 7. 技術

React + TypeScript + Vite+ + Hono + Cloudflare Workers + D1。1 Worker。GitHub Actions は使わず Wrangler でデプロイする。

## 8. MVP 対象外

アカウント、ランキング、カスタム問題、音声、モバイル最適化。
