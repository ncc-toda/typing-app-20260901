# MVP Acceptance Checklist

完成条件の正本。ローカル（`just check` + 実プレイ）と本番 Workers URL の両方で確認する。

## 自動検証

- [ ] `just check` が成功する（`vp check` + `vp test` + `vp build`）

## ゲーム進行

- [ ] タイトルで初級 / 中級 / 上級を選び、120 秒プレイを開始できる
- [ ] 相手メッセージと日本語返信 + ローマ字ガイドが表示される
- [ ] `shi/si`、`chi/ti`、`tsu/tu`、`fu/hu` など表記揺れが通る
- [ ] 誤入力で止まり、正しいキーまで進まない
- [ ] バックスペースで 1 文字戻せる
- [ ] 全文正解で自動送信され、年収が加算される
- [ ] 120 秒で結果画面へ移り、未完了返信は加算されない

## スコアと結果

- [ ] 速度が CPM で表示される
- [ ] 速度補正が `clamp(CPM / 150, 0.5, 1.5)` になっている
- [ ] 正確性補正が 80%=0.8 / 90%=1.0 / 100%=1.2 の線形補間になっている
- [ ] 結果に最終年収、CPM、正確性、ミス数、最大連続、返信完了数が表示される

## 保存と履歴

- [ ] LocalStorage にあるのは匿名 ID だけである
- [ ] プレイ中にキーイベントを毎回送っていない
- [ ] 終了時に `POST /api/results` が一括で保存される
- [ ] 再読込後も `GET /api/stats` で履歴と苦手キー / 指 / 動きが見える
- [ ] 難易度ごとに 10 問（計 30 問）が D1 から取得できる

## UI

- [ ] A案の Slack 風レイアウトである
- [ ] デスクトップでサイドバー + チャットが見える
- [ ] 狭い幅ではサイドバーが折りたたまれる
- [ ] タイトル・結果はキーボードで操作できる
- [ ] コントラストが WCAG AA 相当である

## 本番

- [ ] `*.workers.dev` で問題取得 → 120 秒プレイ → 結果保存 → 履歴再表示ができる
